# Security

Please do not report security vulnerabilities in public issues, discussions or pull requests.

To report a vulnerability in this repository's code (the `cwtrain` library, its CLI or the
recipes), use GitHub's private vulnerability reporting:
[report a vulnerability](https://github.com/coreweave/inference-cookbook/security/advisories/new).
Include what is affected, how to reproduce it, and the impact you see. We will acknowledge the
report and keep you updated while we work on a fix.

For a vulnerability in the CoreWeave platform itself rather than in this repository, contact
[CoreWeave support](https://docs.coreweave.com/support).
